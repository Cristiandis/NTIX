NTIX manages packages across **three** Windows package managers from a single declarative config:

* **winget** - Microsoft's official package manager
* **Chocolatey** - community-driven package manager
* **Scoop** - developer-focused package manager

Write a Lua config file, run `ntix diff` to preview changes, then `ntix apply` to install, upgrade, or remove packages. NTIX tracks what it manages and cleans up orphans automatically.
